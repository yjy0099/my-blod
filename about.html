关于我

在校学生，目前在两个方向上花的时间最多：数据分析与可视化，以及分布式存储系统。这个博客用来存放这两个方向的学习记录。

我在做什么

  • 用 Python 生态（numpy / pandas / matplotlib / seaborn / pyecharts）做端到端的数据分析练习
  • 研读 HDFS 相关材料，把分布式存储的原理拆成能讲清楚的笔记
  • 把学到的东西写成文章，逼自己把逻辑理顺

关于这个博客

纯静态站点，没有框架也没有构建步骤：文章是 posts/ 目录下的 Markdown 文件，加一篇文章只要丢个文件再跑一次索引脚本。选这个方案的唯一理由是——它十年后还能打开。
