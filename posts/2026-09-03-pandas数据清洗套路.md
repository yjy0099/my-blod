## 套路一：先看全貌，别急着洗

```python
df.info()          # 类型 + 缺失情况
df.describe()      # 数值列的分布
df.isna().sum()    # 每列缺多少
```

这三行跑完，数据脏在哪基本就有数了。跳过这步直接清洗，等于闭着眼睛改数据。

## 套路二：缺失值按列分别处理

不要无脑 `dropna()`，会丢掉大量行。按列判断：

```python
df['city'] = df['city'].fillna('未知')
df['amount'] = df['amount'].fillna(df['amount'].median())
df = df.dropna(subset=['order_id'])   # 主键缺失才删
```

原则：**类别列填众数或"未知"，数值列填中位数，主键缺失才删行**。

## 套路三：类型转换放在清洗第一步

字符串类型的日期和金额是后续所有分析出错的根源。

```python
df['order_date'] = pd.to_datetime(df['order_date'], errors='coerce')
df['amount'] = pd.to_numeric(df['amount'], errors='coerce')
```

`errors='coerce'` 会把解析失败的变成 `NaN`，而不是直接抛异常中断。

## 套路四：去重要看清业务主键

```python
df = df.drop_duplicates(subset=['order_id'], keep='last')
```

`keep` 参数很关键：`first` 保留首次，`last` 保留最新。订单类数据通常要 `last`。

## 套路五：异常值用分位数截断

比拍脑袋设阈值靠谱：

```python
q1, q3 = df['amount'].quantile([0.25, 0.75])
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr
df = df[(df['amount'] >= lower) & (df['amount'] <= upper)]
```

## 套路六：用 groupby + agg 一次算多个指标

```python
summary = df.groupby('category').agg(
    order_count=('order_id', 'count'),
    total_amount=('amount', 'sum'),
    avg_amount=('amount', 'mean'),
).round(2)
```

命名聚合（Named Aggregation）比 `groupby().agg({})` 之后再改列名清爽得多。

## 套路七：拆出时间维度再画图

```python
df['month'] = df['order_date'].dt.to_period('M')
df['hour'] = df['order_date'].dt.hour
```

时间序列分析里，这两列能直接喂给 seaborn 画趋势图和热力图。

> 最后提醒一句：**清洗过程要保留原始数据**。我的习惯是 `df_raw` 只读，`df = df_raw.copy()` 之后所有操作都在副本上，改崩了大不了重跑。
